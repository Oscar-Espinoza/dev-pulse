## Context

DevPulse is a **portfolio project**: an uptime/latency monitoring API. Users register monitors (a URL + HTTP method + expected status + check interval); a background scheduler inside the same FastAPI process performs recurring async HTTP checks and records results. The repo is empty (one README line, one initial commit) — everything here is greenfield.

Decisions already made with the user:
- **SQLAlchemy 2.0** typed ORM (`Mapped[]`/`mapped_column`) + separate Pydantic schemas — NOT SQLModel.
- **API-key auth**: each `User` has an `api_key`; requests send `X-API-Key`. No JWT/passwords.
- **Alembic** (async template) for schema management — no `create_all` in production startup.
- **APScheduler 3.11.x** (`AsyncIOScheduler`) — 4.0 is still pre-release as of Aug 2026 and its docs warn against production use.

**Goal:** A deployable FastAPI service where CRUD on monitors dynamically drives per-monitor recurring HTTP checks via an in-process APScheduler, storing every outcome (success, timeout, connection error, wrong status) as a `CheckResult` row.

**Architecture:** Single FastAPI process. Lifespan context builds: async engine (Neon-aware URL normalization) → `async_sessionmaker` → shared `httpx.AsyncClient` → `MonitorScheduler` (wraps `AsyncIOScheduler`), all stored on `app.state`. Routes get the DB session and scheduler via dependencies; create/update/delete of a monitor calls `scheduler.sync_monitor`/`remove_monitor` to adjust exactly that one job. Check jobs re-read the monitor row each run and always write a `CheckResult` instead of raising.

**Tech Stack:** Python 3.12, FastAPI 0.141.x, SQLAlchemy 2.0.51 (asyncio), asyncpg 0.31, Alembic 1.19, APScheduler 3.11.3, httpx 0.28, pydantic 2.13 + pydantic-settings 2.15, structlog 26.1, pytest 9 + pytest-asyncio 1.4 + aiosqlite (tests).

## Global Constraints

- Python `>=3.12` (machine has 3.12.3; no `uv` installed — use `python3 -m venv .venv` + `pip install -e ".[dev]"`).
- `apscheduler>=3.11,<4.0` — **must stay on 3.x**; use `AsyncIOScheduler`, never the 4.0 pre-release API.
- Scheduler lifecycle wired via FastAPI **lifespan** context manager — never `@app.on_event`.
- Every check job: `max_instances=1`, `coalesce=True` (spec: safe against overlapping jobs).
- Per-user limits enforced at the API layer from settings: max **20** active monitors, min interval **60** seconds (defaults; env-overridable).
- Neon compatibility: `DATABASE_URL` from env; normalize `postgresql://` → `postgresql+asyncpg://`, strip `sslmode`/`channel_binding` query params (asyncpg rejects them), pass `ssl=True` instead, and set `statement_cache_size=0` when the host contains `-pooler` (pgbouncer breaks asyncpg's prepared-statement cache).
- Structured logging via **structlog** only — no `print`, no bare `logging` calls in app code.
- All app code: full type hints + docstrings on modules, classes, and public functions.
- Tests: pytest with `asyncio_mode = "auto"`; DB tests on in-memory aiosqlite; HTTP mocked with `httpx.MockTransport`; **no real network calls in tests**.

```python
"""structlog configuration for the whole application."""

import logging
import sys

import structlog


def configure_logging(*, json_logs: bool = False, level: int = logging.INFO) -> None:
    """Configure structlog once at startup.

    Args:
        json_logs: Emit JSON lines (production) instead of pretty console output.
        level: Root stdlib logging level; APScheduler/uvicorn logs flow through it.
    """
    logging.basicConfig(format="%(message)s", stream=sys.stdout, level=level)
    renderer: structlog.typing.Processor = (
        structlog.processors.JSONRenderer() if json_logs else structlog.dev.ConsoleRenderer()
    )
    structlog.configure(
        processors=[
            structlog.contextvars.merge_contextvars,
            structlog.stdlib.add_logger_name,
            structlog.stdlib.add_log_level,
            structlog.processors.TimeStamper(fmt="iso", utc=True),
            structlog.processors.StackInfoRenderer(),
            structlog.processors.format_exc_info,
            renderer,
        ],
        wrapper_class=structlog.stdlib.BoundLogger,
        logger_factory=structlog.stdlib.LoggerFactory(),
        cache_logger_on_first_use=True,
    )
```

```python
"""SQLAlchemy 2.0 ORM models: User, Monitor, CheckResult."""

from __future__ import annotations

import secrets
from datetime import datetime, timezone

from sqlalchemy import (
    JSON,
    DateTime,
    ForeignKey,
    MetaData,
    String,
    Text,
)
from sqlalchemy.dialects.postgresql import JSONB
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship

NAMING_CONVENTION = {
    "ix": "ix_%(column_0_label)s",
    "uq": "uq_%(table_name)s_%(column_0_name)s",
    "ck": "ck_%(table_name)s_%(constraint_name)s",
    "fk": "fk_%(table_name)s_%(column_0_name)s_%(referred_table_name)s",
    "pk": "pk_%(table_name)s",
}

# JSONB on Postgres, plain JSON elsewhere (sqlite in tests).
JSONVariant = JSON().with_variant(JSONB(), "postgresql")


def utcnow() -> datetime:
    """Timezone-aware current UTC time (SQLAlchemy python-side default)."""
    return datetime.now(timezone.utc)


def generate_api_key() -> str:
    """Return a URL-safe random API key."""
    return secrets.token_urlsafe(32)


class Base(DeclarativeBase):
    """Declarative base with a deterministic constraint naming convention."""

    metadata = MetaData(naming_convention=NAMING_CONVENTION)


class User(Base):
    """An account that owns monitors, identified by an API key."""

    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    email: Mapped[str] = mapped_column(String(255), unique=True, index=True)
    api_key: Mapped[str] = mapped_column(
        String(64), unique=True, index=True, default=generate_api_key
    )
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), default=utcnow
    )

    monitors: Mapped[list[Monitor]] = relationship(
        back_populates="user", cascade="all, delete-orphan"
    )


class Monitor(Base):
    """A recurring HTTP check definition owned by a user."""

    __tablename__ = "monitors"

    id: Mapped[int] = mapped_column(primary_key=True)
    user_id: Mapped[int] = mapped_column(
        ForeignKey("users.id", ondelete="CASCADE"), index=True
    )
    url: Mapped[str] = mapped_column(String(2048))
    method: Mapped[str] = mapped_column(String(10), default="GET")
    expected_status: Mapped[int] = mapped_column(default=200)
    interval_seconds: Mapped[int] = mapped_column()
    headers: Mapped[dict[str, str]] = mapped_column(JSONVariant, default=dict)
    is_active: Mapped[bool] = mapped_column(default=True)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), default=utcnow
    )
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), default=utcnow, onupdate=utcnow
    )

    user: Mapped[User] = relationship(back_populates="monitors")
    check_results: Mapped[list[CheckResult]] = relationship(
        back_populates="monitor", cascade="all, delete-orphan", passive_deletes=True
    )


class CheckResult(Base):
    """Outcome of one HTTP check run against a monitor."""

    __tablename__ = "check_results"

    id: Mapped[int] = mapped_column(primary_key=True)
    monitor_id: Mapped[int] = mapped_column(
        ForeignKey("monitors.id", ondelete="CASCADE"), index=True
    )
    status_code: Mapped[int | None] = mapped_column(default=None)
    response_time_ms: Mapped[float] = mapped_column()
    success: Mapped[bool] = mapped_column()
    checked_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), default=utcnow, index=True
    )
    error_message: Mapped[str | None] = mapped_column(Text(), default=None)

    monitor: Mapped[Monitor] = relationship(back_populates="check_results")
```

```python
"""Async engine construction (Neon-aware) and the request-scoped DB session."""

from collections.abc import AsyncIterator
from typing import Annotated, Any

from fastapi import Depends, Request
from sqlalchemy.engine import URL, make_url
from sqlalchemy.ext.asyncio import (
    AsyncEngine,
    AsyncSession,
    async_sessionmaker,
    create_async_engine,
)


def prepare_engine_args(database_url: str) -> tuple[URL, dict[str, Any]]:
    """Normalize a raw DATABASE_URL into (SQLAlchemy URL, asyncpg connect_args).

    Handles Neon-style connection strings:
    - ``postgresql://`` is rewritten to ``postgresql+asyncpg://``.
    - ``sslmode``/``channel_binding`` query params (rejected by asyncpg) are
      stripped; ``ssl=True`` is passed via connect_args instead.
    - Hosts containing ``-pooler`` (Neon's pgbouncer endpoint) get
      ``statement_cache_size=0`` because transaction-mode pgbouncer breaks
      asyncpg's prepared-statement cache.

    Non-Postgres URLs (e.g. sqlite for tests) pass through untouched.
    """
    url = make_url(database_url)
    connect_args: dict[str, Any] = {}
    if url.drivername in {"postgres", "postgresql"}:
        url = url.set(drivername="postgresql+asyncpg")
    if url.drivername == "postgresql+asyncpg":
        query = dict(url.query)
        sslmode = query.pop("sslmode", None)
        query.pop("channel_binding", None)
        url = url.set(query=query)
        if sslmode not in (None, "disable"):
            connect_args["ssl"] = True
        if url.host is not None and "-pooler" in url.host:
            connect_args["statement_cache_size"] = 0
    return url, connect_args


def build_engine(database_url: str, *, echo: bool = False) -> AsyncEngine:
    """Create the application's async engine.

    ``pool_pre_ping`` revalidates pooled connections, which matters for Neon's
    scale-to-zero behavior (idle connections get dropped server-side).
    """
    url, connect_args = prepare_engine_args(database_url)
    return create_async_engine(
        url, echo=echo, connect_args=connect_args, pool_pre_ping=True
    )


async def get_db(request: Request) -> AsyncIterator[AsyncSession]:
    """FastAPI dependency yielding a request-scoped ``AsyncSession``.

    The session factory is created in the lifespan context and stored on
    ``app.state.session_factory``.
    """
    session_factory: async_sessionmaker[AsyncSession] = request.app.state.session_factory
    async with session_factory() as session:
        yield session


DbSession = Annotated[AsyncSession, Depends(get_db)]
```

```python
"""Performs one HTTP check and records its outcome as a CheckResult."""

import time
from dataclasses import dataclass

import httpx
import structlog
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker

from app.models import CheckResult, Monitor

logger = structlog.stdlib.get_logger(__name__)


@dataclass(slots=True)
class CheckOutcome:
    """Result of a single HTTP probe, independent of persistence."""

    status_code: int | None
    response_time_ms: float
    success: bool
    error_message: str | None


def _elapsed_ms(start: float) -> float:
    """Milliseconds elapsed since ``start`` (a perf_counter timestamp)."""
    return round((time.perf_counter() - start) * 1000, 2)


async def perform_check(
    client: httpx.AsyncClient,
    *,
    url: str,
    method: str,
    expected_status: int,
    headers: dict[str, str],
) -> CheckOutcome:
    """Probe ``url`` and classify the outcome.

    Never raises for HTTP-level problems: timeouts, connection failures and
    unexpected status codes all come back as a failed ``CheckOutcome``.
    """
    start = time.perf_counter()
    try:
        response = await client.request(method, url, headers=headers)
    except httpx.TimeoutException:
        return CheckOutcome(None, _elapsed_ms(start), False, "Request timed out")
    except httpx.HTTPError as exc:
        return CheckOutcome(
            None, _elapsed_ms(start), False, f"{type(exc).__name__}: {exc}"
        )
    elapsed = _elapsed_ms(start)
    if response.status_code == expected_status:
        return CheckOutcome(response.status_code, elapsed, True, None)
    return CheckOutcome(
        response.status_code,
        elapsed,
        False,
        f"Expected status {expected_status}, got {response.status_code}",
    )


async def run_monitor_check(
    monitor_id: int,
    session_factory: async_sessionmaker[AsyncSession],
    client: httpx.AsyncClient,
) -> None:
    """Scheduler job body: load the monitor, probe it, persist a CheckResult.

    Reads the monitor fresh each run so config edits apply immediately, and
    silently no-ops if the monitor was deleted or deactivated after the job
    fired (delete/reschedule races).
    """
    async with session_factory() as session:
        monitor = await session.get(Monitor, monitor_id)
        if monitor is None or not monitor.is_active:
            logger.warning("monitor_check_skipped", monitor_id=monitor_id)
            return
        outcome = await perform_check(
            client,
            url=monitor.url,
            method=monitor.method,
            expected_status=monitor.expected_status,
            headers=monitor.headers,
        )
        session.add(
            CheckResult(
                monitor_id=monitor.id,
                status_code=outcome.status_code,
                response_time_ms=outcome.response_time_ms,
                success=outcome.success,
                error_message=outcome.error_message,
            )
        )
        await session.commit()
        logger.info(
            "monitor_checked",
            monitor_id=monitor.id,
            url=monitor.url,
            success=outcome.success,
            status_code=outcome.status_code,
            response_time_ms=outcome.response_time_ms,
        )
```

```python
"""In-process scheduling of recurring monitor checks via APScheduler 3.x."""

from datetime import timezone

import httpx
import structlog
from apscheduler.job import Job
from apscheduler.jobstores.base import JobLookupError
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from apscheduler.triggers.interval import IntervalTrigger
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker

from app.models import Monitor
from app.services.checker import run_monitor_check

logger = structlog.stdlib.get_logger(__name__)

#: Late checks are still run if within this many seconds of their slot,
#: instead of being discarded (e.g. after event-loop stalls).
MISFIRE_GRACE_SECONDS = 30


class MonitorScheduler:
    """Owns the AsyncIOScheduler and maps monitors to interval jobs.

    One job per active monitor, keyed ``monitor:{id}``. Jobs run with
    ``max_instances=1`` and ``coalesce=True`` so a slow check can never
    overlap with itself, and a backlog collapses into a single run.
    """

    def __init__(
        self,
        session_factory: async_sessionmaker[AsyncSession],
        http_client: httpx.AsyncClient,
    ) -> None:
        self._session_factory = session_factory
        self._http_client = http_client
        self._scheduler = AsyncIOScheduler(timezone=timezone.utc)

    @staticmethod
    def job_id(monitor_id: int) -> str:
        """APScheduler job id for a monitor."""
        return f"monitor:{monitor_id}"

    async def start(self) -> None:
        """Schedule all active monitors from the DB, then start the scheduler.

        Must be called with a running event loop (FastAPI lifespan).
        """
        async with self._session_factory() as session:
            result = await session.execute(
                select(Monitor).where(Monitor.is_active.is_(True))
            )
            monitors = result.scalars().all()
        for monitor in monitors:
            self.schedule_monitor(monitor.id, monitor.interval_seconds)
        self._scheduler.start()
        logger.info("scheduler_started", scheduled_jobs=len(monitors))

    async def shutdown(self) -> None:
        """Stop the scheduler without waiting for in-flight jobs."""
        self._scheduler.shutdown(wait=False)
        logger.info("scheduler_stopped")

    def schedule_monitor(self, monitor_id: int, interval_seconds: int) -> None:
        """Add — or replace, if it already exists — the job for one monitor."""
        self._scheduler.add_job(
            self._run_check,
            trigger=IntervalTrigger(seconds=interval_seconds),
            args=[monitor_id],
            id=self.job_id(monitor_id),
            replace_existing=True,
            max_instances=1,
            coalesce=True,
            misfire_grace_time=MISFIRE_GRACE_SECONDS,
        )
        logger.info(
            "monitor_job_scheduled",
            monitor_id=monitor_id,
            interval_seconds=interval_seconds,
        )

    def remove_monitor(self, monitor_id: int) -> None:
        """Remove a monitor's job; a missing job is not an error."""
        try:
            self._scheduler.remove_job(self.job_id(monitor_id))
            logger.info("monitor_job_removed", monitor_id=monitor_id)
        except JobLookupError:
            logger.debug("monitor_job_already_absent", monitor_id=monitor_id)

    def sync_monitor(
        self, monitor_id: int, *, is_active: bool, interval_seconds: int
    ) -> None:
        """Converge one monitor's job to its desired state (API create/update)."""
        if is_active:
            self.schedule_monitor(monitor_id, interval_seconds)
        else:
            self.remove_monitor(monitor_id)

    def get_job(self, monitor_id: int) -> Job | None:
        """Return the APScheduler job for a monitor, if scheduled."""
        return self._scheduler.get_job(self.job_id(monitor_id))

    async def _run_check(self, monitor_id: int) -> None:
        """Job entrypoint: one check run, guaranteed never to raise.

        HTTP-level failures are already recorded by ``run_monitor_check``;
        this guard catches infrastructure errors (e.g. DB unreachable) so an
        individual failure can never kill the scheduler loop.
        """
        try:
            await run_monitor_check(
                monitor_id, self._session_factory, self._http_client
            )
        except Exception:
            logger.exception("monitor_check_errored", monitor_id=monitor_id)
```

```python
"""CRUD for monitors, with per-user limits and live scheduler synchronization."""

from typing import Annotated

import structlog
from fastapi import APIRouter, Depends, HTTPException, Query, status
from sqlalchemy import func, select
from sqlalchemy.ext.asyncio import AsyncSession

from app.config import Settings, get_settings
from app.database import DbSession
from app.dependencies import CurrentUser, SchedulerDep
from app.models import CheckResult, Monitor
from app.schemas import CheckResultRead, MonitorCreate, MonitorRead, MonitorUpdate

logger = structlog.stdlib.get_logger(__name__)

router = APIRouter(prefix="/monitors", tags=["monitors"])

SettingsDep = Annotated[Settings, Depends(get_settings)]


def _validate_interval(interval_seconds: int, settings: Settings) -> None:
    """422 if the requested interval undercuts the configured minimum."""
    if interval_seconds < settings.min_interval_seconds:
        raise HTTPException(
            status_code=status.HTTP_422_UNPROCESSABLE_ENTITY,
            detail=(
                f"interval_seconds must be at least {settings.min_interval_seconds}"
            ),
        )


async def _count_active_monitors(
    session: AsyncSession, user_id: int, *, exclude_id: int | None = None
) -> int:
    """Active monitors owned by ``user_id`` (optionally excluding one)."""
    stmt = (
        select(func.count())
        .select_from(Monitor)
        .where(Monitor.user_id == user_id, Monitor.is_active.is_(True))
    )
    if exclude_id is not None:
        stmt = stmt.where(Monitor.id != exclude_id)
    return (await session.execute(stmt)).scalar_one()


async def _get_owned_monitor(
    session: AsyncSession, monitor_id: int, user_id: int
) -> Monitor:
    """Load a monitor owned by the user, or 404 (never leaks others' ids)."""
    monitor = await session.get(Monitor, monitor_id)
    if monitor is None or monitor.user_id != user_id:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND, detail="Monitor not found"
        )
    return monitor


@router.post("", response_model=MonitorRead, status_code=status.HTTP_201_CREATED)
async def create_monitor(
    payload: MonitorCreate,
    user: CurrentUser,
    session: DbSession,
    scheduler: SchedulerDep,
    settings: SettingsDep,
) -> Monitor:
    """Create a monitor and (if active) schedule its recurring check."""
    _validate_interval(payload.interval_seconds, settings)
    if payload.is_active:
        active = await _count_active_monitors(session, user.id)
        if active >= settings.max_active_monitors_per_user:
            raise HTTPException(
                status_code=status.HTTP_409_CONFLICT,
                detail=(
                    "Active monitor limit reached "
                    f"({settings.max_active_monitors_per_user})"
                ),
            )
    monitor = Monitor(
        user_id=user.id,
        url=str(payload.url),
        method=payload.method,
        expected_status=payload.expected_status,
        interval_seconds=payload.interval_seconds,
        headers=payload.headers,
        is_active=payload.is_active,
    )
    session.add(monitor)
    await session.commit()
    await session.refresh(monitor)
    scheduler.sync_monitor(
        monitor.id,
        is_active=monitor.is_active,
        interval_seconds=monitor.interval_seconds,
    )
    logger.info("monitor_created", monitor_id=monitor.id, user_id=user.id)
    return monitor


@router.get("", response_model=list[MonitorRead])
async def list_monitors(user: CurrentUser, session: DbSession) -> list[Monitor]:
    """List the requesting user's monitors."""
    result = await session.execute(
        select(Monitor).where(Monitor.user_id == user.id).order_by(Monitor.id)
    )
    return list(result.scalars().all())


@router.get("/{monitor_id}", response_model=MonitorRead)
async def get_monitor(
    monitor_id: int, user: CurrentUser, session: DbSession
) -> Monitor:
    """Fetch one of the requesting user's monitors."""
    return await _get_owned_monitor(session, monitor_id, user.id)


@router.patch("/{monitor_id}", response_model=MonitorRead)
async def update_monitor(
    monitor_id: int,
    payload: MonitorUpdate,
    user: CurrentUser,
    session: DbSession,
    scheduler: SchedulerDep,
    settings: SettingsDep,
) -> Monitor:
    """Partially update a monitor and converge its scheduled job."""
    monitor = await _get_owned_monitor(session, monitor_id, user.id)
    updates = payload.model_dump(exclude_unset=True)
    if "url" in updates:
        updates["url"] = str(updates["url"])

    new_interval = updates.get("interval_seconds", monitor.interval_seconds)
    _validate_interval(new_interval, settings)

    will_be_active = updates.get("is_active", monitor.is_active)
    if will_be_active:
        others = await _count_active_monitors(
            session, user.id, exclude_id=monitor.id
        )
        if others >= settings.max_active_monitors_per_user:
            raise HTTPException(
                status_code=status.HTTP_409_CONFLICT,
                detail=(
                    "Active monitor limit reached "
                    f"({settings.max_active_monitors_per_user})"
                ),
            )

    for field, value in updates.items():
        setattr(monitor, field, value)
    await session.commit()
    await session.refresh(monitor)
    scheduler.sync_monitor(
        monitor.id,
        is_active=monitor.is_active,
        interval_seconds=monitor.interval_seconds,
    )
    logger.info("monitor_updated", monitor_id=monitor.id, changed=sorted(updates))
    return monitor


@router.delete("/{monitor_id}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_monitor(
    monitor_id: int,
    user: CurrentUser,
    session: DbSession,
    scheduler: SchedulerDep,
) -> None:
    """Delete a monitor (and, via cascade, its results); unschedule its job."""
    monitor = await _get_owned_monitor(session, monitor_id, user.id)
    await session.delete(monitor)
    await session.commit()
    scheduler.remove_monitor(monitor_id)
    logger.info("monitor_deleted", monitor_id=monitor_id, user_id=user.id)


@router.get("/{monitor_id}/results", response_model=list[CheckResultRead])
async def list_results(
    monitor_id: int,
    user: CurrentUser,
    session: DbSession,
    limit: Annotated[int, Query(ge=1, le=500)] = 50,
) -> list[CheckResult]:
    """Most recent check results for a monitor, newest first."""
    await _get_owned_monitor(session, monitor_id, user.id)
    result = await session.execute(
        select(CheckResult)
        .where(CheckResult.monitor_id == monitor_id)
        .order_by(CheckResult.checked_at.desc(), CheckResult.id.desc())
        .limit(limit)
    )
    return list(result.scalars().all())
```

```python
"""DevPulse application entrypoint: app factory and lifespan wiring."""

from collections.abc import AsyncIterator
from contextlib import asynccontextmanager

import httpx
import structlog
from fastapi import FastAPI
from sqlalchemy.ext.asyncio import async_sessionmaker

from app.config import get_settings
from app.database import build_engine
from app.logging import configure_logging
from app.routers import monitors, users
from app.services.scheduler import MonitorScheduler

logger = structlog.stdlib.get_logger(__name__)


@asynccontextmanager
async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    """Build shared resources on startup; tear them down on shutdown.

    Startup: engine -> session factory -> shared HTTP client -> scheduler
    (which loads all active monitors and begins checking). Everything is
    stored on ``app.state`` for dependencies to reach.
    """
    settings = get_settings()
    engine = build_engine(settings.database_url, echo=settings.echo_sql)
    session_factory = async_sessionmaker(engine, expire_on_commit=False)
    http_client = httpx.AsyncClient(
        timeout=settings.http_timeout_seconds, follow_redirects=True
    )
    scheduler = MonitorScheduler(session_factory, http_client)

    app.state.engine = engine
    app.state.session_factory = session_factory
    app.state.scheduler = scheduler

    await scheduler.start()
    logger.info("app_started")
    try:
        yield
    finally:
        await scheduler.shutdown()
        await http_client.aclose()
        await engine.dispose()
        logger.info("app_stopped")


def create_app() -> FastAPI:
    """Application factory."""
    configure_logging(json_logs=get_settings().json_logs)
    app = FastAPI(
        title="DevPulse",
        description="Uptime & latency monitoring with an in-process async scheduler.",
        version="0.1.0",
        lifespan=lifespan,
    )
    app.include_router(users.router)
    app.include_router(monitors.router)

    @app.get("/healthz", tags=["meta"])
    async def healthz() -> dict[str, str]:
        """Liveness probe (used by Render health checks)."""
        return {"status": "ok"}

    return app


app = create_app()
```

````markdown
# DevPulse

Uptime & latency monitoring API. Register a monitor (URL + method + expected
status + interval) and an in-process async scheduler checks it on schedule,
recording every outcome — including timeouts and connection failures — as
queryable results.

**Stack:** FastAPI · SQLAlchemy 2.0 (async) · Postgres (Neon-ready) ·
APScheduler 3.x · httpx · Alembic · structlog

## How it works

```
FastAPI lifespan
 ├─ async engine (Neon-aware URL normalization, pooler-safe)
 ├─ shared httpx.AsyncClient
 └─ MonitorScheduler (APScheduler AsyncIOScheduler)
      ├─ on startup: schedules one interval job per active monitor
      ├─ on API create/update/delete: syncs exactly that monitor's job
      └─ each run: HTTP probe -> CheckResult row (never crashes the loop)
```

Per-user limits (defaults): max 20 active monitors, minimum interval 60s.
````
